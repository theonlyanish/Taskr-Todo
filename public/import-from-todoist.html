Import your tasks from Todoist into Taskr

Taskr is a free todo app with Kanban and Calendar views that works offline and needs no sign-up. If you are leaving Todoist, you can bring a project across in a few clicks: export it as a CSV file, then import that file into Taskr.

Open Taskr

Step 1: export from Todoist

  1. In Todoist, open the project you want to move.
  2. Open the project menu (the three dots next to the project name).
  3. Choose Export as CSV (sometimes labelled Export as a template).
  4. Save the .csv file somewhere you can find it.

Todoist exports one project at a time, so repeat this for each project you want in Taskr. Any CSV file under 5 MB and 1,000 tasks can be imported in one go.

Step 2: import into Taskr

  1. Open taskr-todo.vercel.app and sign in. Import needs a free account, because imported tasks are saved to your account so they are not lost if your browser data is cleared. Creating one takes an email address and a password, or a Google account.
  2. Open the account menu in the top right and choose Import tasks. You can also press Ctrl+K and type import.
  3. Pick the CSV file you exported.
  4. Taskr shows a preview: how many tasks and subtasks it found and whether any dates could not be read. Click Import to add them to your list.

Imported tasks are added to the tasks you already have. Nothing is deleted or replaced. They go into the list you have open at the time (Personal, unless you have switched), so to give a Todoist project its own list in Taskr, create the list from the menu beside the logo, open it, and then import.

What each Todoist field becomes

Taskr reads the standard Todoist template columns. This is the exact mapping:

Todoist columnIn Taskr
TYPE = taskA task. Every imported task starts in the To Do column, because the Todoist export does not say whether a task is complete.
CONTENTThe task title.
DESCRIPTIONThe task description.
INDENT1 is a top-level task. 2 or more makes the row a subtask of the nearest top-level task above it. Taskr has one level of subtasks, so deeper levels are flattened onto that task.
DATEThe due date, when it is a plain date such as 2026-11-03, Nov 3, 3 November 2026, today or tomorrow. Times are dropped, because Taskr stores dates only. A date without a year is taken as the next time it comes round.
TYPE = sectionTaskr has lists rather than sections, and a whole Todoist project maps to one list (see above). The section name is added to the description of each task in it as Section: <name>, so nothing is lost.
TYPE = noteComments are appended to the description of the task they belong to.
PRIORITY, labels, assigneesNot imported. Taskr does not have priorities, labels or assignees.

Recurring dates such as every Monday, every weekday or every month become repeating tasks, due on the next matching date; completing one adds the next. Dates Taskr can't read, such as ambiguous ones like 03/04/2026 or patterns like every 2nd Monday, are imported without a due date and the original text is kept in the description as Todoist date: …, so you can set a date yourself. The import preview tells you how many dates this affected.

Importing from other apps

The same importer accepts any CSV file with a title column, so exports from spreadsheets, TickTick, Microsoft To Do (via Excel) or your own scripts work too. Column names are matched case-insensitively:

  • Title (required): title, task, name, content, summary, subject or task name
  • Description: description, notes, note, details or body
  • Status: status, state, completed, done or complete. Values like done, completed, true, yes or x become Completed; in progress, doing, started or wip become In Progress; anything else is To Do.
  • Due date: due date, due, date, deadline or due_date, read the same way as Todoist dates
  • Parent: parent, parent task or parent title, holding the title of another row, makes the row a subtask of it

Commas, semicolons and tabs all work as separators, and quoted fields may contain line breaks.

What Taskr does differently from Todoist

  • Free, with nothing locked. Every view and feature is free. There is no Pro tier, no task limit and no ads.
  • No account to get started. You can use Taskr without signing up, and your tasks stay in your browser. A free account is only needed for cross-device sync, import and export.
  • Works offline. Without an account, Taskr keeps working with no connection at all. Read more in how Taskr works offline.
  • Kanban and Calendar built in. The same tasks appear as a list, a board with To Do, In Progress and Done columns, or a month or week calendar with an Unscheduled tray.
  • Simpler on purpose. Lists stand in for projects, and repeating tasks are covered, but there are no labels, filters, priorities or shared workspaces, and reminders only work while Taskr is open in a tab. If you rely on those, Taskr may be too small for you.
  • Your data leaves as easily as it arrived. Export everything to a Markdown file at any time from the account menu.

Frequently asked questions

Will my completed tasks come across as completed?
No. The Todoist CSV export does not include completed tasks or a completion flag, so every imported task starts in To Do. A generic CSV with a status column keeps its statuses.

Can I import the same file twice?
Yes, but the tasks will be duplicated. Taskr does not de-duplicate on import.

Is my file uploaded anywhere?
The file is read in your browser. Only the resulting tasks are saved to your account, in the same way as a task you type by hand.
